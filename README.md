# Happy Birthday, Samriti di

A responsive birthday website built with plain HTML, CSS, and JavaScript. Your three photos are included in `assets/`.

## Preview locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Extract this ZIP.
2. Upload the project to a new GitHub repository.
3. In Vercel, choose **Add New → Project** and import that repository.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (root).
5. Deploy.

No API keys or environment variables are needed. The site is static and mobile-friendly.
